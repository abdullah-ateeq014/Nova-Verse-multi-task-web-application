🚀 About Nova Verse

Nova Verse is an interactive all-in-one web application created by Abdullah Ateeq, a Grade 10 student.

It combines AI, education, entertainment, games, sports, health tools, search, productivity, shopping, and discovery into one modern digital universe.

▶️ How to Run
Method 1 — Directly
Download the Nova Verse HTML file.
Double-click the .html file.
It will open in your browser.
Wait for the startup screen.
Nova Verse will launch automatically.
Method 2 — VS Code
Open the project in VS Code.
Open the HTML file.
Use Live Server if installed.
Open the generated browser page.
🏆 Coding Week Project

Nova Verse was designed as a Coding Week competition project.

The goal is to demonstrate how one web application can combine multiple useful experiences into a single interface:

AI + Education + Games + Health + Sports + Entertainment + Productivity

The project focuses on both functionality and presentation, including interactive navigation, animations, dashboards, tools, and a dedicated presentation experience.
